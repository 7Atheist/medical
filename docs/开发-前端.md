# 板块① 前端开发说明（Vue3）

> 你负责整个前端。技术栈 Vue3 + Vite + Element Plus + Pinia + Axios。
> 接口契约见 [API.md](./API.md)，所有字段以它为准，**不要私自改字段名**。

## 你的职责范围
- `frontend/src/` 全部页面与组件
- 聊天式评估交互（`Assessment.vue`，最关键，476行）
- 语音识别交互（`utils/speech.js`）
- 三档字号放大（`utils/fontScale.js` + `styles/global.css`）
- 后台管理界面（`views/admin/`）
- 前端代理配置（`vite.config.js`）
- **不碰** backend/ 和 ai-service/ 的代码，改接口先找接口 owner

## 你的主要文件
```
frontend/src/
├─ views/                  # 页面
│  ├─ Login.vue            # 登录
│  ├─ Home.vue             # 首页
│  ├─ Assessment.vue       # ★ 聊天式评估（核心）
│  ├─ Report.vue           # 报告
│  ├─ History.vue          # 历史
│  └─ admin/               # 后台管理（8个页面）
├─ components/FontScaleBar.vue   # 字号放大条
├─ api/index.js            # 所有接口封装（含 AI 服务调用）
├─ api/http.js             # axios 拦截器（自动带 token）
├─ store/user.js           # 登录状态
├─ utils/speech.js         # ★ 语音识别（点击切换录音）
├─ utils/fontScale.js      # 字号缩放
└─ styles/global.css       # 全局样式（白底、医院风、简洁）
```

## 启动与验证
```powershell
cd frontend
npm install
npm run dev          # http://localhost:5173
npm run build        # 提交前必须能构建通过
```

## 关键约定
1. **多用白色、简洁、贴近医院**，不要花哨。
2. 评估页是聊天气泡流：护士头像左侧问问题、选项圆角气泡点了即提交、老人回答右侧气泡。
3. 语音识别：点击开始录音、再点停止，识别文本交给 AI 分析（`answerSource=VOICE`）。
4. AI 话术包装：`wrapQuestion()` 5 秒超时就降级用原题，**不能让老人干等**。
5. 接口调用统一走 `api/index.js`，不在页面里直接写 URL。
6. 代码注释用中文。
