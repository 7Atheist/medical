# 板块② 后端开发说明（Spring Boot）

> 你负责业务后端，**同时是三方接口契约的 owner**。技术栈 Java 17 + Spring Boot 3.2 + Spring Data JPA + MySQL 8。
> 接口契约见 [API.md](./API.md)，任何接口字段变更由你统一维护。

## 你的职责范围
- `backend/src/main/java/` 全部逻辑
- 认证（姓名+身份证号实名登录）
- 评估状态机、计分、报告生成、历史清理
- 数据库设计（`deploy/sql/` 10张表）
- 后台管理接口
- 调用 AI 服务（`client/AiServiceClient.java`）
- **作为接口 owner，维护 [API.md](./API.md)**，变更需通知另两板块

## 你的主要文件
```
backend/src/main/java/com/geriatric/assessment/
├─ controller/      # REST 接口
│  ├─ AuthController.java
│  ├─ AssessmentController.java   # ★ 评估流程（核心）
│  ├─ ReportController.java
│  └─ AdminController.java
├─ service/         # 业务逻辑
│  ├─ AssessmentService.java   # ★ 737行，状态机+追问+归一化调用
│  ├─ ScoringService.java      # 计分与风险判定
│  ├─ ReportService.java       # 报告生成
│  └─ AuthService.java
├─ repository/      # JPA 数据访问
├─ entity/          # 实体（10张表对应）
├─ dto/             # ★ 接口传输对象（契约核心）
├─ config/          # 鉴权拦截器、参数、数据初始化
├─ client/AiServiceClient.java   # 调 AI 服务
├─ scheduler/       # 定时任务（草稿/历史清理）
└─ util/            # AES加密、身份证解析
deploy/sql/         # ★ 数据库 schema + 种子数据
```

## 启动与验证
```powershell
cd backend
$env:DB_PASSWORD="你的MySQL密码"
mvn clean package -DskipTests          # 提交前必须构建通过
java -jar target\assessment-backend.jar   # :8080

# 健康检查
Invoke-RestMethod http://localhost:8080/api/health
```

## 关键约定
1. **后端多注释**，每个接口/方法写清作用。
2. **统一响应** `{code, message, data}`（`common/Result.java`），`code=0` 成功。
3. **鉴权**：`config/AuthInterceptor` 校验 `Authorization: Bearer <token>`；后台接口走 `AdminAuthInterceptor`（`ADMIN_TOKEN` 环境变量）。
4. **AI 调用要降级**：AI 服务不可用时，语义归一化降级为词典匹配，不能让评估中断。
5. **敏感字段 AES 加密**（身份证、健康答案）。
6. **计分用 `Double.NEGATIVE_INFINITY`/`POSITIVE_INFINITY`**，禁用 `Double.MIN_VALUE`（最小正数，导致 0 分误判"正常"）。
7. **报告取最新一条**：`findFirstByTaskIdOrderByIdDesc`，禁用 `findByTaskId`（同一任务可能多份报告会报错）。

## 接口 owner 职责
- 任何一方想改接口字段 → 先找你确认
- 你更新 [API.md](./API.md) + 对应代码 → 通知前端、AI
- 数据库表结构变更由你统一改 `deploy/sql/schema.sql`
